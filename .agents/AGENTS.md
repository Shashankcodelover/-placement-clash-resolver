# PLACEMENT CLASH RESOLVER — DAILY OPERATING DIRECTIVES

## DAILY WORKFLOW — ONE COMPLETE THREE-PHASE CYCLE PER DAY

Every session follows a **SINGLE COMPLETE THREE-PHASE CYCLE** combining the **BUILDER**, **REJECTOR**, and **BUILDER (RESOLVER)** identities in strict sequence. This cycle runs **once per day at 12:12 PM** (or when the daily session is started). The standard is **10X improvement per day**.

| **Net Daily Improvement** | 10X measurable advancement over yesterday |
